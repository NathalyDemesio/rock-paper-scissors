# ✊✋✌️ Pedra, Papel e Tesoura (CLI)

Jogo clássico de **Pedra, Papel e Tesoura** desenvolvido em Python para ser jogado diretamente pelo terminal contra o computador, com sistema de contagem de pontos em tempo real e placar final.

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

---

## 📋 Sobre o Projeto

Projeto desenvolvido para praticar lógica de programação e fundamentos da linguagem Python, como estruturas de repetição (`while`), condicionais (`if/elif/else`), manipulação de listas, entrada de dados do usuário e geração de escolhas aleatórias com a biblioteca nativa `random`.

### ✨ Funcionalidades
- **Partidas Contínuas:** O jogo roda em loop até que o jogador decida encerrar digitando `Q`.
- **Validação de Entrada:** Ignora entradas inválidas automaticamente sem quebrar a execução do programa.
- **Placar em Tempo Real:** Contabiliza as vitórias do jogador e do computador a cada rodada.
- **Resumo Final:** Ao sair, exibe a pontuação total de ambos e declara o vencedor geral (vitória, derrota ou empate).

---

## 🎮 Como Jogar

Ao executar o programa, utilize as seguintes teclas para fazer sua jogada:

| Tecla | Ação |
| :---: | :--- |
| **`R`** | Escolhe **Pedra** *(Rock)* |
| **`P`** | Escolhe **Papel** |
| **`T`** | Escolhe **Tesoura** |
| **`Q`** | Encerra o jogo e exibe o resultado final *(Quit)* |
